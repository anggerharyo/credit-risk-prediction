## Credit Risk Prediction
A machine learning project developed to predict credit risk using loan application data, simulating a lending company use case.

### Overview
Developed a credit risk prediction model using loan application data to classify borrowers based on their loan status.

### Methodology
```
1. Data cleaning and preprocessing
2. Handling missing values and outliers
3. Feature encoding and scaling
4. Model development using Logistic Regression and Random Forest
5. Hyperparameter tuning with GridSearchCV
6. Model evaluation using Accuracy, Precision, Recall, and ROC AUC
```

### Results
Logistic Regression was selected as the final model based on the highest test ROC AUC.
